Phase 1｜世界与群系

极地世界与四个群系

Worldgen

winternightak:winter_night 固定午夜视觉，但游戏时间正常推进。大陆噪声划分极地海洋、冰盖、积雪沙滩和冰原。

  • -2…-0.18：极地海洋；-0.18…0.42：冰盖。
  • 0.42…0.43：窄积雪沙滩；0.43…2：冰原。
  • 沙滩从原冰原面积划分，不改变海洋和冰盖阈值；宽度不是固定格数。
PolarWorldgen.java · OCEAN_THRESHOLD / ISLAND_THRESHOLD / BEACH_INLAND_THRESHOLD
world_preset/winter_night.json

地形高度与岸线

Terrain

冰盖顶部为 Y=62。积雪沙滩沙面也以 Y=62 为目标；进入冰原后逐渐补回高度并增加起伏。内陆基础抬升上限为 20。

调节最高高度的主入口是 ISLAND_MAX_RISE；游戏读取生成 JSON，因此还需同步 polar.json 内两处内陆 clamp 的 max。

PolarWorldgen.java · ISLAND_MAX_RISE
noise_settings/polar.json

冻洋与冰山

Ocean

极地海洋温度0.16，只刷新鱿鱼、鳕鱼和鲑鱼。海床10格沙砾，再下方为基岩。浮冰冰山平均每16区块尝试一次，蓝冰冰山每200区块尝试一次；完全沿用原版冰山雪块，雪块受本模组重力影响。

Phase 1｜地层与自然资源

地表剖面

Surface Rules
  • 冰盖：Y=43…62 约20格硬冰，顶部薄雪。
  • 积雪沙滩：薄雪、约3格沙子、永久冻土；无枯树和村庄。
  • 冰原：薄雪、约3格冻结土壤、永久冻土；Y=8…-63 为无矿深板岩，Y=-64为基岩。
  • 永久冻土不可正常挖掘，外观使用本地砂土贴图。

薄雪、雪块重力与冻结土壤

Feature + Mixin

硬冰、冻结土壤和沙子顶面生成薄雪。原版雪块具有沙子式重力。冻结土壤属于铲子可挖方块，硬度0.75，比泥土0.5稍慢；永久冻土保持基岩强度。

Phase 1｜生态与基础物品

动物与狩猎

Ecology

陆地只保留兔、狐狸和狼，海洋只保留鱿鱼、鳕鱼、鲑鱼；兔和狐狸固定雪地外观。主要掉落是生动物肉、油脂和 Cold Sweat 毛皮，不掉皮革。狐狸10%概率叼物，其中肉和毛皮各半。

Phase 2｜燃料与取暖

燃料设备

Heat

公共燃料：木棍2400 tick、小麦2400 tick、油脂1800 tick。设备无燃料熄灭，必须用打火石点火。

  • 油灯：容量36000、热量0.35、范围3、亮度9。
  • 火把：新物品燃料0；放置添料后点火，回收保存余量；手持不供暖。热量0.45、范围3。
  • 营火：容量72000、热量0.9、范围8，可放食物烹制。
  • 加热器加入同一 Cold Sweat 账户后，四种热源共享累计上限2.5。

加热器与太阳灯

Devices

只认六面直接相邻的红石块，不认普通红石信号。加热器热量1.8、范围8，每20 tick检查半径4格的已加载区域；太阳灯关闭亮度0、开启亮度15。

加热器配方为8铁板包围红石；太阳灯为中心红石、四边铁板、四角玻璃。两者只能在极地工作台制作。

Phase 3｜解冻与耕作

解冻土地生命周期

Environment

加热器将范围内有顶盖的冻结土壤变为解冻土壤。它可锄成耕地、铲成路径，支持原版作物、水分、踩踏和退化。失去加热器后通过随机刻重新冻结，室内关机同样冻回去。

只访问已加载区块；未加载边界暂缓冻结。当前按半径判断，不计算墙壁阻隔。

Phase 3｜圣诞树

树苗、生长与叶片

Feature

树苗复用原版两阶段生长、光照≥9、随机刻和骨粉规则，可种在解冻土壤。树高9格，含8根云杉原木、分层叶冠、每装饰层0～3块红/蓝玻璃和顶部南瓜灯；空间不足保留树苗。

独立圣诞树叶使用云杉外观与原版自然消失机制；剪刀或精准采集100%掉自身，普通破坏和自然消失无掉落。

资源与维护规则

目录职责
src/main/java/com/akingno/winternightak/行为、注册、运行时与世界生成源代码。
src/main/resources/assets/winternightak/语言、模型、状态和本地贴图副本；借用贴图应先复制到此处。
src/main/resources/data/winternightak/配方、掉落、Cold Sweat 数据、手工地物与村庄模板池。
src/main/resources/data/minecraft/有意覆盖的原版数据，例如箭配方；会全局影响原版内容。
src/generated/resources/data/winternightak/群系、噪声、维度、预设与结构数据；改变 bootstrap 时必须同步。
Cold Sweat 是必需前置；GeckoLib 不是当前依赖。世界生成 Java 与 JSON 当前采用双维护，修改阈值、高度或群系时必须检查两边一致。

存档与测试边界

  • 群系、地层、粘土、冰山、沙滩和结构分布只在新区块生效；改变群系源时优先新建世界验证。
  • 村民交易通过版本标记迁移；调整已有交易时同步提高对应职业版本。
  • 常规验证只执行编译与 JSON/资源检查，不做远距离地形采样或游戏功能测试。
  • 地层边界建议检查 Y=9、8、-63、-64。
